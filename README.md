# 坦克大战 (Battle City)

一个使用纯 **HTML / CSS / JavaScript** 实现的经典《坦克大战》网页版，单文件、零依赖，双击即可游玩。

## 玩法
- 操作己方坦克，**保护基地（鹰）**，消灭每关所有敌方坦克。
- 敌人会攻击你与基地，基地被击中即游戏结束。
- 每关敌人数量与强度逐渐提升。

## 操作
| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` / `W A S D` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 |
| `Enter` | 开始 / 重新开始 |

## 地图元素
| 元素 | 说明 |
| --- | --- |
| 🧱 砖墙 | 可被子弹摧毁 |
| ⬜ 钢墙 | 不可摧毁（火力满级可击穿） |
| 🌊 水域 | 坦克无法通过，子弹可穿过 |
| 🌲 树林 | 隐藏坦克（画在最上层） |
| 🦅 基地 | 被击中即失败 |

## 道具
| 道具 | 效果 |
| --- | --- |
| ★ 火力 | 升级火力（提升射速，满级可击穿钢墙） |
| ◈ 护盾 | 暂时无敌 |
| 💣 清屏 | 消灭场上所有敌人 |
| ◷ 冻结 | 冻结敌人一段时间 |
| ▣ 加固 | 基地围墙临时变为钢墙 |
| ＋ 生命 | 增加一条命 |

## 运行
直接用浏览器打开 `index.html` 即可，无需构建或依赖。

或本地起一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 特性
- 纯 Canvas 渲染，像素风格
- 敌人 AI（追踪基地 / 玩家、随机转向）
- 4 种敌人：普通 / 快速 / 强力 / 装甲
- 多关卡、难度递增
- Web Audio 音效
- 最高分本地记录 (localStorage)
- 响应式布局
